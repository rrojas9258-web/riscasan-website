# Ricardo AI — by Riscasan

Ricardo AI is the multilingual AI assistant in the Riscasan ecosystem.

## V1
- Text chat
- Voice-ready interface
- Image/document upload-ready interface
- English, Haitian Creole, French, Spanish
- Premium Riscasan visual identity

## Stack
- Next.js
- React
- OpenAI Responses API
- Supabase (auth/history in next phase)
